01 — Why run locally?

Your machine, your rules

Every time you type into ChatGPT, your words travel to someone else's server. What if your data — medical records, legal drafts, company secrets — never had to leave your laptop? That's the promise of local LLMs. Same AI magic, entirely on your hardware.

🔒 privacy

100% private

Prompts never leave your computer. Nobody sees your data — not OpenAI, not Google, nobody.

💰 cost

$0 per query, forever

Cloud APIs charge per token. At scale that's hundreds per month. Local costs electricity and nothing else.

✈️ offline

Works anywhere

On a flight? No Wi-Fi? Your local LLM doesn't care. Once downloaded, it runs without internet.

🎛️ control

Full control

Temperature, system prompts, context length — every parameter is yours. No guardrails you didn't set.

⚡ speed

No rate limits

Cloud APIs throttle you. Locally, run as many queries as your hardware allows. No queues.

🧠 learning

Best way to learn

Want to understand AI? Run it yourself, poke the parameters, and watch what happens.

Cloud AI is renting a flat. Local AI is owning the house. Same walls — but you hold the keys.

— the pitch, in one sentence

02 — The model landscape

Pick your AI brain

An LLM is just a big file of numbers — a trained brain you download. Different brains, different strengths. Pick the one that fits your job.

🦙 llama 3.1

Meta's all-rounder

8B, 70B, 405B sizes. The 8B runs on a laptop and handles chat, code, and writing. Open-source, free.

💨 mistral

Lightweight champion

French-made, fast as lightning. 7B model punches above its weight — some benchmarks beat GPT-3.5.

💎 gemma 2

Google's compact gem

2B and 9B sizes. The 2B runs on a phone. Google-trained quality in a tiny package.

🔬 phi-3

Microsoft's overachiever

Small model, extremely high-quality data. The 3.8B Mini is shockingly capable for its size.

🐋 deepseek

Open-source giant

Fully open, rivals GPT-4 on many benchmarks. 67B model is a powerhouse.

🌐 qwen 2.5

Multilingual ace

Alibaba's hidden gem — strong reasoning, great at instructions, excellent with multiple languages.

💡 Beginner rule: Start with Llama 3.1 8B. It's the "Honda Civic" of LLMs — reliable, well-supported, runs everywhere.

06 — Shrinking the model

Quantization: the JPEG trick

An LLM is a giant pile of numbers at 16-bit precision (like a RAW photo). Quantization rounds them to 4 bits — like saving as JPEG. 4× smaller, barely any quality loss. Click a level to see how.

08 — Python integration

Copy, paste, run

Ollama exposes an OpenAI-compatible API on localhost. Any code that works with ChatGPT works locally — just change the base URL.

ollama_chat.py
from openai import OpenAI # Point to your local Ollama server client = OpenAI( base_url="http://localhost:11434/v1", api_key="not-needed" ) response = client.chat.completions.create( model="llama3.1", messages=[ {"role": "system", "content": "You are a helpful assistant."}, {"role": "user", "content": "Explain quantization in one paragraph."} ], temperature=0.7 ) print(response.choices[0].message.content)
💡 The magic line: base_url="http://localhost:11434/v1" — that's the only change between cloud and local. Your entire codebase stays the same.

10 — Local vs Cloud

The honest comparison

Both have strengths. The best answer is usually "use both."

🏠

Local LLM

your machine, your rules
✓100% private — nothing leaves your machine
✓$0 per query, forever
✓Works offline — airplane, cabin, anywhere
✓Full control over every parameter
~Setup takes 20 min the first time
✗7B models lag GPT-4 for hard reasoning
✗Needs decent hardware (8 GB VRAM+)
VS
☁️

Cloud API

someone else's computer, their rules
✓Frontier-class quality out of the box
✓No hardware setup — just an API key
✓Always the latest model improvements
~Convenient but expensive at scale
✗Every prompt goes to a third party
✗Pay per token — $600+/month heavy use
✗No internet = no AI

Use both. Local for privacy, drafts, bulk work. Cloud for hard reasoning. They complement each other.
